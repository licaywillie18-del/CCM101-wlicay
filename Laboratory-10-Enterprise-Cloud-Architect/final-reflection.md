# Mission 10: Final Journey Reflection – The Enterprise Cloud Architect

Throughout CCM101 – Cloud Computing, we learned many important skills from Mission 1 to Mission 10. We started by learning how to install and manage Ubuntu Server using VirtualBox, work with Linux commands, manage users, and use SSH. We also learned about cloud networking, port forwarding, and public cloud services. In the later missions, we explored Docker, container images, volumes, and Docker Compose to run applications using containers. These activities helped us understand how cloud systems work and how to manage them properly.

In Mission 10, we applied what we learned by setting up a WordPress website and a MariaDB database on an Ubuntu Server virtual machine. We used Docker Compose to manage the containers and persistent volumes to keep the data safe. We also configured the UFW firewall to allow only the necessary connections, such as SSH on Port 22 and web access on Port 8080, while keeping the database private. Another important task was creating a Bash backup script that automatically saves the database and WordPress files every day at 2:00 AM using Cron. We also faced challenges with network connections, port settings, and database backups, which helped us improve our troubleshooting skills.

Overall, Mission 10 helped us understand that cloud computing is not only about setting up servers and applications. It also involves security, proper system management, data protection, and automation. By completing all ten missions, we gained practical knowledge that we can use in future IT projects. These experiences also helped prepare us for possible careers in cloud computing, DevOps, and IT infrastructure. This journey taught us the importance of patience, problem-solving, and continuous learning in the field of technology.
