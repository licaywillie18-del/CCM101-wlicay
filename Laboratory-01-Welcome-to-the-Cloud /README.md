
# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced the Linux operating system through the KillerCoda cloud environment. It focused on learning Linux commands, gathering system information, organizing files, and creating a GitHub portfolio.

## Objectives

- Access a cloud-based Linux environment.
- Explore Linux commands.
- Gather system information.
- Organize files and directories.
- Create a GitHub repository.
- Document work using Markdown.

## Activities Performed

- Launched Ubuntu 24.04 in KillerCoda.
- Created a new Linux user with sudo privileges.
- Gathered system information.
- Created Markdown files.
- Built a Cloud Computing Portfolio repository.
- Captured screenshots.

## Linux Commands Used

- whoami
- pwd
- hostname
- adduser
- usermod
- su
- uname
- lscpu
- free
- df
- mkdir

- ls

## Skills Learned

- Linux navigation
- Linux user management
- System information gathering
- Markdown documentation
- GitHub repository management
