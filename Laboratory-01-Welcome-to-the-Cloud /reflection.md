# Laboratory Reflection: Ubuntu 24.04 & GitHub Portfolio

## 1. Introduction
In this laboratory activity, I learned how to use the Ubuntu Linux terminal in KillerCoda and manage my files on GitHub. I completed tasks like creating a user, checking system information, creating folders, and uploading my work to GitHub.

---

## 2. What I Did in the Checkpoints

### Checkpoint 1: User Creation
* I created a new non-root user named `wlicay` using the `adduser` command.
* I switched from the `root` user to `wlicay` using `su - wlicay` and checked my username and location using `whoami` and `pwd`.

### Checkpoint 2: System Information
* I checked the system details, including the Linux version (Ubuntu 24.04 LTS), processor, RAM, and disk space.
* I saved all these system details into a file named `system-information.md` using the `nano` editor.

### Checkpoint 3: Creating Folders and Files
* I created new folders (`Notes`, `Reports`, `Screenshots`, `Workspace`) using the `mkdir -p` command.
* I created an `about-me.md` file in the `Notes` folder containing my student information.

### Checkpoints 4 & 5: GitHub Setup
* I set up my repository named `CCM101-wlicay` on GitHub.
* I organized my project inside the `Laboratory-01-Welcome-to-the-Cloud` folder with all required Markdown files and screenshots.

---

## 3. What I Learned & Challenges
* **Typing Commands Carefully:** I made a few small typing mistakes in the terminal (like typing wrong passwords or incorrect commands), but I learned how to fix them quickly.
* **Organizing Files:** I learned how important it is to keep files neat and write good documentation using Markdown.

---

## 4. Conclusion
This activity helped me build basic skills in using the Linux command line and managing projects on GitHub. These skills are very useful for cloud computing and software development.
