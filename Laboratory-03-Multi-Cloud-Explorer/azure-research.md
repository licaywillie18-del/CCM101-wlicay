

# AZURE Research

## Brief Overview
Microsoft Azure is a cloud computing platform developed by Microsoft and launched in 2010. It provides more than 200 cloud products and services that help organizations build, deploy, manage, and scale applications, data, and other IT resources. Azure also supports areas such as artificial intelligence, analytics, computing, databases, security, and storage.
## Global Infrastructure
Microsoft Azure has 70+ regions around the world. These regions are organized into geographies, which help with data residency and geographic requirements.
Each Azure region contains datacenters connected through a high-capacity network. Many Azure regions also provide availability zones, which are separate groups of datacenters designed to provide high availability and resiliency.
Azure's global infrastructure helps organizations achieve global reach, lower latency, and improved reliability.
## Cloud Management Console
The Azure Portal is a unified console provided by Microsoft. It allows users to build, manage, and monitor Azure resources through a web browser. It also allows users to manage and monitor their cloud resources and services in one place.
## Four Core Services
### Azure Functions
Azure Functions is a serverless computing solution that allows developers to run code without managing the underlying servers. It is event-driven and uses triggers to execute code when a specific event occurs, such as an HTTP request, timer, or file being added.
### Azure SQL Database
Azure SQL Database is a platform-as-a-service (PaaS) cloud database service. It handles many database management tasks, such as patching, upgrading, monitoring, and backups, reducing the need for manual administration.
### Azure Blob Storage
Azure Blob Storage is a cloud storage service designed to store large amounts of unstructured data, such as images, audio, video, documents, and other files. The stored data can be accessed over HTTP or HTTPS.
### Azure Virtual Machines
Azure Virtual Machines is a cloud computing service that provides scalable virtual computers, allowing users to run operating systems and applications in Azure without needing physical hardware.
## Three Advantages

### Global Reach
Azure has more than 70 regions around the world, making its cloud services available to users in different locations and helping organizations improve availability and reliability.
### Scalability
Azure allows organizations to increase or decrease their cloud resources based on their needs. This means a company can scale its computing, storage, or other resources without having to purchase and upgrade physical servers.
### Security
Azure provides security features that help protect data, applications, and cloud resources from security threats.

## Typical Enterprise Use Cases

### Data Storage
Companies can use Azure Blob Storage to store large amounts of unstructured data such as documents, images, audio, and video. The stored data can be accessed over HTTP or HTTPS, making it convenient for organizations to retrieve and manage their files when needed.

### Database Management

Companies can use Azure SQL Database to store and manage business data such as customer information and transactions. Azure handles database management tasks such as upgrading, patching, monitoring, and backups, reducing the need for manual administration.
### Application Hosting

Companies can use Azure to host their applications in the cloud. Azure provides the necessary cloud infrastructure and resources, allowing developers to focus more on building and improving applications instead of managing physical servers.
